## 2. 环境与方法

### 2.1 渲染

- **真实 Handlebars 模板 + 真实 CSS**：Foundry 14 核心 CSS、Font Awesome、CoC7 `system.css`，以及模组 `tokens.css / sheet.css / npc.css / container.css`。

- 环境记录：Node v26.9.0、Google Chrome 155.0.8059.85、macOS；`meta.json` 内含 git HEAD、branch 与每个 CSS/模板的 mtime，可复现快照。

### 2.3 自动审计（tools/audit.mjs + tools/audit-page.js）

CDP 复用单个 Chrome 实例逐页执行，注入**只读**探针（仅读取 DOM / computed style）：

1. **文字对比度**：采集文本节点矩形与 computed color → 文字临时透明化（inline `!important`，保留背景/图片/边框）→ 截图 → 取矩形内背景像素中位数 → WCAG 计算。正文要求 4.5:1，次要文字（`em/small/mute/dim/hint` 等）与大字 3:1；`<3:1` 记 P1，边缘值记 P2，同选择器+同色合并计数。采样区限定为「文本矩形 ∩ 窗口 ∩ 全部滚动/裁切祖先」，可见比例 <72% 不参与。
2. **横向溢出/裁切**：页面横向滚动（P0）、元素横向探出窗口、被 `overflow:hidden` 祖先裁切、关键标签 ellipsis；`input/textarea/select` 内部滚动不算裁切；纵向滚动内容不误报。
3. **空/破图**：`img.naturalWidth===0`、`<use href="#symbol">` 找不到对应 symbol。
4. **控件核心样式污染（启发式）**：`appearance` 未复位、字体栈命中 Foundry 核心字体；CSS 内联后不再使用「无自绘背景」规则。
5. **字体**：只检查可见且含拉丁字符的文本；`document.fonts.check` 带 computed `style/weight`（Garamond italic 为独立 face）。
6. **tab 一致性**：导航/内容区对应、激活 tab 与参数一致、非 GM 不出现 `notes`/`keeper`。
7. **状态/视角/模式**：`--state` 的 `.is-low`/`.is-chip.is-active`、`--formula` 的 `.is-formula`、`--compact` 的 `.is-compact`、observer 无编辑控件。
8. **布局**：关键元素重叠、横幅占比、激活 tab 尺寸、关键组件缺失。
9. **容器专项**：行图标 `filter` 是否压暗、分组头是否含 `[data-action="toggleGroup"]`、空态是否有空状态提示。

3. **纵向滚动误报、CJK/italic 字体误报、隐藏 tab、input 内部滚动、联系表裁切**：见 §5.4。
