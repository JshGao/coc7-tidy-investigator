# 调查员的桌面，也可以很 Tidy

**CoC7 Tidy 角色卡 · v0.8.3 发布**
Foundry VTT 14 · Call of Cthulhu 7e（CoC7 ≥ 8.16）

![封面](screenshots/cover.png)

> 把跑团时要用的东西，摆到最顺手的位置。
>
> 三张可选安装的角色卡：调查员、生物 / NPC、容器。
> 不替换系统默认卡，装上就能用，随时切回去。

---

## 为什么做这张卡

CoC7 系统自带的调查员卡功能齐全，但跑团时总在重复几个动作：翻技能、对半值、找武器、算成长。
这张卡只做一件事——**把高频信息摊开，把低频操作收好**。

- 抬头就能看到：血量、魔法值、理智、幸运、伤害加值、八个特性
- 一页就能查完：技能、武器、背包、背景、成长
- 结算不用手忙脚乱：一键成长，自动记录，随时撤销

## 功能一览

### 1. 一屏看清角色状态

![技能页](screenshots/skills.png)

顶部横幅承担了「驾驶舱」：资源条、八枚盾形特性、状态芯片、今日 SAN。
点击「理智」或「幸运」直接发起检定；状态芯片点一下就能开关。
七个标签页横向排开：技能 / 简表 / 物品 / 背景 / 成长 / 笔记 / 效果。

### 2. 技能：找得到、投得动、改得了

![编辑态技能](screenshots/skills-edit.png)

- 搜索框即时过滤；按数值 / 名称 / 自定义三种方式排序
- 专长技能（射击、格斗…）自动折叠分组
- 已收藏技能显示实心星，左侧收藏栏点击即可投骰
- 解锁后拆出「职业 / 兴趣 / 成长点」三列，直接改点数

### 3. 简表：开团后的驾驶舱

![简表](screenshots/summary.png)

武器速查表：技能%、伤害、射程、每轮、弹药、故障，一点就攻击，再一点直接掷伤害（自动处理伤害加值与半伤害加值）。
下面是六类「已投入点数」的技能芯片，战斗技能常驻显示，跑团时不用再翻技能页。

### 4. 物品：自己的背包自己整理

![物品](screenshots/possessions.png)

武器 / 护具 / 书籍 / 法术 / 天赋 / 道具 / 状态分节，分组可折叠、编辑态可拖拽排序。
右键任意物品：打开 / 加入收藏 / 删除；道具数量直接改。

### 5. 背景：七要素和关键链接

![背景](screenshots/background.png)

按规则书的七要素整理：外貌形象、思想信念、宝贵之物、意义非凡之地、重要之人、特质、伤疤和恐惧症。
任意一项可以勾选为「关键链接」，支持多选，一眼看到这个角色最在乎什么。

### 6. 成长：幕间结算不再手忙脚乱

![成长](screenshots/growth.png)

勾选成长技能 →「一键成长」批量检定，自动清空标记。
每一次检定都单独记录，按**可编辑的模组名**分组；可以改成长后的数值、逐条撤销、重建本次成长。
克苏鲁神话这类特殊技能，还可以直接手动改值。

### 7. 笔记、效果与一些细节

![笔记](screenshots/notes.png)

- 守秘笔记、书籍阅读进度、SAN 损失事件、神话标记、一键清除全部状态
- 效果页新增 / 打开 / 启停 / 删除
- 收藏侧栏、右键菜单、八向窗口缩放与尺寸记忆
- 紧凑模式：小屏幕或信息密集时更省空间

![紧凑模式](screenshots/compact.png)

---

### 8. 生物 / NPC 卡：KP 的战斗面板

同一套 Tidy 语言，换成守秘人最顺手的信息排布：

- 横幅直接给 **每轮攻击次数、SAN 损失、护甲**，战斗页默认打开
- 武器表一点攻击、再点掷伤害（自动处理伤害加值与霰弹枪分档）
- 特殊能力（天赋）速查、移动方式增删、骰子宏拖入即用
- 编辑态支持 **公式模式**：给怪物写 `3D6*5`，一键掷特性或取平均
- 技能/物品/描述/守秘四页与调查员卡同款操作

![生物卡·战斗](screenshots/npc-combat.png)

![生物卡·编辑态](screenshots/npc-combat-edit.png)

### 9. 容器卡：箱子也要整整齐齐

给「容器」Actor 的紧凑卡片：96px 头像、容器件数、按类型汇总的芯片，
内容 / 描述 / 守秘 / 效果四页；拖入物品、改数量、拖拽排序，和系统容器卡数据完全互通。

![容器卡](screenshots/container.png)

## 安装

Foundry VTT → 附加组件 → 模块 → 安装模块 → **Manifest URL** 填入：

```
https://raw.githubusercontent.com/JshGao/coc7-tidy-investigator/main/module/module.json
```

安装后在「管理模块」启用，再到角色「配置界面 → 角色卡」选择 **CoC7 Tidy 调查员卡**、**CoC7 Tidy NPC / 生物卡** 或 **CoC7 Tidy 容器卡**。

- 完全可选：不替换系统默认卡，随时切回
- 数据兼容：沿用 CoC7 原生数据结构，不产生额外数据
- 无依赖：纯 Handlebars + CSS，无构建步骤
- 开源：MIT 许可，欢迎提 issue / PR

仓库：<https://github.com/JshGao/coc7-tidy-investigator>
