# 05 · 美术风格设计（v0.9「调查员档案」）

> 本文档定义 CoC7 Tidy 角色卡的视觉语言，供后续所有卡片（调查员 / 生物·NPC / 容器）共同遵守。
> 视觉样稿与截图由 `tools/` 下的无头渲染管线生成（见第 9 节），改变样式后必须重新出图验收。

---

## 1. 设计目标

**关键词：1920 年代调查员档案 · 黄铜饰线 · 做旧纸张 · 克制的宇宙恐怖**

- **档案感**：角色卡像一份从阿卡姆报社档案柜里抽出来的卷宗——深色漆面封皮、黄铜压印、纸张泛黄。
- **层次感**：横幅（封皮）→ 内容（纸张）→ 面板（卡片纸）→ 输入（凹印）四层材质，靠光影和黄铜细线区分，而不是靠彩色块。
- **克制**：装饰只出现在边缘、分隔线、角饰与徽记上；数据区域必须保持高可读性。
- **一致性**：三张卡共用同一套 token、横幅、盾徽、表格、面板语言；容器卡只是"更小的同一份档案"。

**不要做的事**

- 不复制 Tidy 5e Sheets 的图片素材或代码；所有纹章、角饰、盾徽、图标均为本项目自制 SVG/CSS。
- 不使用高饱和纯色大色块、圆角胶囊泛滥、发光描边堆叠等"游戏 HUD"风格。
- 不牺牲 700px 最小宽度、紧凑模式、编辑态下的可读性。

## 2. 色彩

所有颜色都通过 `module/styles/tokens.css` 的 CSS 变量提供，组件中**不要写死颜色**（必要的 banner 内特殊色除外）。

| `--c7t-on-brass` | `#33291a` | 浅色带上的深字 |

### 暗色（`theme-dark`）——墨色皮革 + 黄铜反光

- 纸张 `#14151a`，卡片 `#1d1f26`，描边 `#35363f`，黄铜 `#c3a76f`，牛血红提亮为 `#b45a63`。
- 暗色下**不要**把亮色直接反相；保持"深色皮革 + 低亮度黄铜"的关系。
- 纹理噪声在暗色下降低透明度，避免脏点。

### 背景纹理

- 纸张：`--c7t-paper`（多层径向渐变 + 纤维线）+ `--c7t-noise`（SVG feTurbulence 噪声）。
- 横幅：`--c7t-banner-layers`（黄铜侧光 + 牛血红暗角 + 漆面渐变）+ 极淡的放射星芒 + `--c7t-noise-strong`。
- 纹理只用于**大面**，不要盖在文字上；面板保持 90% 以上不透明度。

## 3. 字体

三款字体全部本地打包（`module/assets/fonts/`，均为 OFL，授权文件在 `licenses/`）：

| CSS 变量 | 字族 | 用途 |
|---|---|---|
| `--c7t-font-display` | **Cinzel** → 中文回落宋体 | 姓名、Tab、章节标题、工具条标题、卡片标题 |
| `--c7t-font-body` | **Roboto Condensed** → 苹方 | 数据、表格、按钮、输入、正文 |
| `--c7t-font-long` | **EB Garamond** → 中文回落宋体 | 富文本正文（背景、描述、守秘笔记） |

规则：

- 数值一律 `font-variant-numeric: tabular-nums`。
- 小型全大写标签：`font-size:9.5–10px; letter-spacing:.12–.16em; font-weight:700`。
- 标题行距紧凑（1.04），正文行距 1.6–1.7。
- 中文标题使用宋体回落即可，不要为中文另配黑体标题。

## 4. 结构材质

### 4.1 横幅（封皮）

- 背景：`--c7t-banner-layers`；顶部 1px 内高光，底部 1px 黄铜线 + 外投影。
- 装饰：4 个 Art Deco 角饰（`#c7t-corner`）与暗纹印记（`#c7t-seal`），透明度 0.03–0.10，只做氛围。
- 横幅内部文字使用 `--c7t-banner-text / -dim / -mute`，**不要**直接用内容区的 `--c7t-text`。
- 横幅高度不是固定值，由头像（132px）+ 资源/特性/状态行决定；紧凑模式整体缩小约 10%。

### 4.2 头像

- 3px 黄铜渐变边框（`linear-gradient(148deg, …)`）+ 外圈 1px 细线 + 内阴影。
- 图片 `filter: sepia(.14) saturate(.92) contrast(1.04)`，悬停时恢复饱和度并提亮边框。
- 不要做成正圆；保持 4px 圆角方框。

### 4.3 资源卡（HP/MP/SAN/幸运）

- 结构：`图标徽记 + 名称 + 数值(最大)` 一行，第二行 5px 进度条。
- 进度条：深色凹槽 + 10% 刻度 + 渐变填充 + 顶部高光；`is-low` 时呼吸闪烁。
- 图标为自制线稿（`#c7t-ico-hp/mp/san/lck`），各自带资源色。
- 狭窗（≤730px）隐藏图标，保证名称完整。
- 编辑态：`.c7t-vitals.is-editing` 变为 2 列网格，给输入框留宽度。

### 4.4 特性盾徽

- 自制 SVG（`#c7t-shield`）：黄铜外框 + 深色描金内场 + 顶部菱形 + 底部小菱形。
- 尺寸约 96px 高，8 枚等距；悬停上浮 2px 并提亮。
- 缩写用 Cinzel 小号 + 大间距；数值 27px Roboto Condensed Bold；半值/五分之一 9.5px。
- 空值（NPC）显示 `—`，盾徽降低对比，不要隐藏。

### 4.5 Tab

- Cinzel 12.5px、0.055em 字距；激活项：微弱黄铜底光 + 底部 2px 黄铜渐变线 + 轻发光。
- 图标沿用 Font Awesome，尺寸 14px、透明度 0.82。
- Tab 行背景为横幅底部的加深带；不要使用 Foundry 默认 `nav.tabs` 的展开式布局（已有覆盖）。

### 4.6 内容区（纸张）

- `background-color: var(--c7t-bg)` + `background-image: var(--c7t-noise), var(--c7t-paper)`。
- 顶部有 12–22px 的内阴影，营造"从封皮下露出纸张"的层次。
- 侧栏为更深的纸张 + 右侧内阴影；标题前有 5px 铜色菱形。
- 内容区左右留白 16px，卡片间距 9–13px。

## 5. 组件规格

### 5.1 数据表

- 容器：卡片纸 + 1px 描边 + 轻投影 + 顶部 1px 白色高光。
- 表头：**墨色带**（`--c7t-ink-band`）+ `--c7t-on-ink` 小号全大写字 + 底部黄铜细线。
- 行高 33px（紧凑 27px），奇偶行 4% 黄铜底纹，悬停 14% 底纹 + 左侧 2px 黄铜条。
- 行图标：20px 黄铜描边小徽章；可投骰行悬停时变为牛血红底并发光。
- 数值列右对齐 + tabular-nums；名称列加粗、超长省略。
- 成长标记：13px 凹印方框，选中为牛血红渐变 + 浅色对勾。

### 5.2 面板 / 章节 / 分组

- **章节头（`.c7t-section-head`）**：墨色带 + 黄铜字（与表头同族）。
- **分组头（`.c7t-group-head` / `.c7t-skill-group-head` / `.c7t-growth-group-head`）**：浅色"羊皮纸带" + 左侧 3px 黄铜条 + `--c7t-brass-deep` 文字；暗色下反相为半透明浅带。
- **背景要素卡（`.c7t-bio-card`）**：卡片纸 + 内高光 + 右下角线角饰；关键链接卡为牛血红左侧 3px 条 + 牛血红头带。
- **货币条**：墨色"账本"横条，黄铜小标签 + 浅色数字。

### 5.3 按钮与芯片

- **主按钮**：牛血红漆面渐变 + 顶部内高光 + 悬停提亮/外发光；文字浅色。
- **幽灵按钮**：透明底 + 黄铜描边 + 米色文字（`.c7t-btn-ghost`，NPC 用）。
- **状态芯片**：深色半透明底 + 1px 黄铜线 + 3px 圆角；激活态按类型着色（重伤=红、疯狂=紫、其它=橙、死亡/濒死=深红），带内发光。
- **技能芯片**：卡片纸 + 黄铜描边，悬停上浮 1px + 牛血红描边。
- 禁止胶囊化（除 tab 计数、标记计数等极小元素外）。

### 5.4 输入

- 浅色凹印输入：`--c7t-panel` 底 + 1px `--c7t-line` 边 + 内阴影；聚焦时黄铜描边 + 2px 柔光。
- 横幅内输入：深色半透明底 + 浅色文字；聚焦黄铜描边。
- 输入字号不小于 12px；数值输入居中或右对齐。

### 5.5 空状态 / 滚动条

- 空状态：虚线黄铜框 + 中央自制星芒纹 + Cinzel 标题 + Garamond 提示。
- 滚动条：10px，黄铜渐变滑块，透明轨道。

## 6. 三张卡的差异

| 组件 | 调查员卡 | 生物 / NPC 卡 | 容器卡 |
|---|---|---|---|
| 横幅 | 头像 132、4 资源、8 盾徽、状态 + 今日 SAN | 头像 132、资源（空值隐藏）、8 盾徽、状态 + 战斗条 | 头像 96、名称 + 计数芯片，紧凑 |
| 内容首屏 | 技能 / 简表 / 物品 / 背景 / 成长 / 笔记 / 效果 | 战斗 / 技能 / 物品 / 描述 / 守秘 / 效果 | 内容 / 描述 / 守秘 / 效果 |
| 特有组件 | 收藏侧栏、简表技能芯片、成长记录 | 战斗速览条、武器表、特殊能力、移动方式、公式模式、宏 | 物品分节、计数芯片 |
| 视觉重心 | 横幅 + 技能表 | 横幅 + 武器表 + 战斗条 | 横幅 + 物品分节 |

具体组件仍需遵循本文件；NPC / 容器可增加**局部变体**，但不得引入新的主色或第二种装饰语言。

## 7. 状态与动效

- 过渡统一 `.16s cubic-bezier(.22,.8,.32,1)`；进度条 0.35s。
- 悬停只做 1–2px 位移、亮度/描边变化、轻微外发光；不做旋转、弹跳。
- 可投骰元素必须有明确的可点击暗示（光标、图标底色变化、悬停发光）。
- `prefers-reduced-motion` 下建议关闭低血量脉冲（可选增强）。

---

## 8. 可访问性 / 约束

- 正文与底色的对比度 ≥ 4.5:1；次要文字 ≥ 3:1。
- 最小窗口 700×500；780 为默认；必须检查 700 / 780 / 1020 三档。
- 紧凑模式、编辑态、暗色主题、无 GM 权限（隐藏笔记/守秘）都要成立。
- 所有新增图标使用 `parts/icons.hbs` 的 `<symbol>`；不要引入外部图片依赖。
- 不改变数据字段、action 名称、表单 name；纯视觉改动优先。

## 9. 出图与验收（tools/）

完整命令行、矩阵规模、审计规则见 [`tools/README.md`](../tools/README.md)。最常用：

```bash
node tools/render.mjs --matrix --out /tmp/c7t-art/html   # 标准评审矩阵（全卡 × tab × 亮/暗 + 状态）
node tools/shot.mjs  --dir /tmp/c7t-art/html --out /tmp/c7t-art/png
node tools/shot.mjs  --contact /tmp/c7t-art/png --cols 4 # 联系表（按真实纵横比）
node tools/audit.mjs --dir /tmp/c7t-art/html --out /tmp/c7t-art/audit --crops

# 单张
node tools/render.mjs --sheet npc --tab combat --theme dark --edit --out /tmp/x
node tools/shot.mjs  --dir /tmp/x --out /tmp/x-png
```

要点：

- 渲染使用真实 Handlebars 模板 + 真实 CSS（tokens/sheet/npc/container）+ Foundry 14 核心 CSS + CoC7 系统 CSS，窗口外壳为 `.application.coc7-tidy > .window-content`。
- **CSS 全部内联进生成的 HTML**：无头 Chrome 里 `file://` 外部样式存在加载竞态/缓存，会让截图出现「白底原生按钮、黑框行图标」等**假污染**。若发现此类现象，先确认是否用了最新 `tools/render.mjs`，不要直接改 CSS。
- 截图 `--budget` 默认 20000ms，不要调小。
- Foundry 的 tab 激活类名是 `.active`（v14），不是 `.is-active`；自定义 tab/按钮/Tab 计数等需要同时兼容。
- 每次改动至少自查：亮/暗 × 锁定/编辑 × 700/780/1020 宽，以及本卡全部 Tab。
- 截图验收由视觉 QA 负责；评审记录写入 `docs/06-视觉验收报告.md`。
