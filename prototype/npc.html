行为与栖息地
深潜者在近海的沉船与海底石城中建立聚落，与人类沿海村落保持隐秘往来。它们崇拜克苏鲁与父神达贡，会掳走人类进行杂交。遭遇时通常先以深渊凝视削弱调查员，再以利爪与撕咬近身。

看这张样稿的 6 个点

  • 横幅是同一套语言：头像 + 身份 + 8 盾徽 + 资源块 + 状态/战斗行 + tab，与调查员卡一致。
  • 战斗优先：默认打开「战斗」；每轮攻击、SAN 损失、护甲在横幅底行与战斗页速览条双处展示。
  • 空值隐藏：深潜者没有 SAN / 幸运 → 锁定态不显示；点「进入编辑态」才出现输入框。
  • 缺值盾徽：APP / EDU 显示「—」；编辑态可补值，公式模式下输入公式。
  • 轻量取舍：无收藏侧栏、无货币条、无成长列；天赋在战斗页速查 + 物品页列表。
  • 守秘是 GM 页：笔记 + 骰子宏 + 清除状态；无神话标记 / SAN 事件（NPC 无这些字段）。

可以点的地方

  • 工具条：切换暗色 / 宽度 780（看窄窗降级）/ 进入编辑态 / 公式模式（需先编辑态）。
  • Tab 行：战斗 / 技能 / 物品 / 描述 / 守秘 / 效果 可切换。
  • 状态芯片可点亮；技能/武器行悬停出现操作按钮；分组标题可折叠。
  • 锁定按钮在横幅右上角；编辑态下所有数值原位变成输入框（示意，无真实保存）。
